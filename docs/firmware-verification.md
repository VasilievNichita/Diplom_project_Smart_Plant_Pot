# Проверка прошивки 0.3

Дата: 10 октября 2026. Это результаты программной проверки; плата, датчики и помпы не подключались.

## Выполнено

| Проверка | Результат |
|---|---|
| PlatformIO `monitor` | Успешная сборка ESP32, RAM 39 816 B, flash приложения 549 077 B |
| PlatformIO `irrigation` | Успешная сборка ESP32, RAM 39 856 B, flash приложения 551 345 B |
| PlatformIO `pump-test` | Успешная сборка ESP32, RAM 21 736 B, flash приложения 304 809 B |
| C++ тесты `firmware/scripts/test-native.ps1` | 15 сценариев пройдены |
| Node.js `site` tests | 27 тестов пройдены |
| Изолированный серверный симулятор | Пройден; база только в памяти, без изменения настоящих данных |
| PDF схемы | Все 4 страницы отрисованы и визуально проверены |

Сборка: PlatformIO Core 6.1.16, Espressif32 6.9.0, Arduino-ESP32 2.0.17, Xtensa GCC 8.4.0. Профили собраны без приватного `secrets.h`; это заготовки для последующей настройки сети, а не готовые прошивки с пользовательскими ключами. Host C++ тесты: g++ 16.2.0, Node.js тесты: 24.19.0.

C++ сценарии выполняют общую с ESP32 логику таймера и блокировок: граничная длительность, запрет второго насоса, отключение по пяти условиям, uptime за пределами 32-битного счётчика, превышение времени, стабилизация контактов, диапазон калибровки, контрольный CRC, UTC, сохранённое принятие команды, повтор ID, повреждение записи и кольцевой журнал. Это не эмулятор ESP32 и не проверка драйверов периферии.

Серверные тесты дополнены приёмом измеренной длительности с небольшой задержкой, фиксацией превышения без обрезания числа, снятием разрешения при превышении, учётом увеличенного расхода в бюджете, защищённым чтением результата и ручным восстановлением неизвестной команды без выдуманного объёма.

## Ещё не выполнено

Электрические измерения, реальная I2C/Wi-Fi связь платы, работа ADC с купленными пробами, поведение flash при отключении питания, реальные задержки watchdog/контактов, пусковые токи и нагрев, точность дозирования, самотёк, долговременный прогон. Нельзя заявлять их успешность по компиляции или по host-тестам. Протокол будущих проверок находится в [инструкции сборки](hardware-assembly.md).
