# Автономная USB камера Folium

Это отдельный этап публикации клиента. Серверный API камеры и его интерфейс
подготовлены локально, но ещё не входят в публичный `main` на момент этого
коммита. Инструкция подключения ниже относится к сборке с этим расширением;
клиент сам по себе не добавляет соответствующие маршруты в старый сервер.
Тесты клиента запускаются независимо от расширения:
`python -m unittest discover -s camera -v`.

Контракт сервера: `GET /api/camera-device/config` возвращает `serverTime` и
`camera` с полями `id`, `kind`, `enabled`, `revision`, `intervalSeconds`,
`lastFrameAt`. `POST /api/camera-device/photos` принимает `requestKey`,
`revision`, `capturedAt`, `mime` и `base64`. Оба маршрута требуют Bearer ключ
именно этой камеры; сервер отвечает за проверку привязки, интервала и лимита
данных. Примеров настоящих ключей и пользовательских снимков в этом этапе нет.

Клиент сохраняет фото без открытой вкладки браузера. ПК и сервер должны работать.
Физическое подключение: USB камера на стойке над одним горшком → USB порт ПК.
Камера не подключается к GPIO контроллера насосов. Светильник крепится отдельно,
чтобы корпус не закрывал обзор; нельзя направлять блики прямо в объектив.

1. В реальном саду открой «Фотоосмотр» и создай точку типа «Отдельная камера через API».
2. Сохрани скачанный JSON в `private/camera/`, не в публичном репозитории.
3. Сначала проверь кадр камерой в обычном приложении: виден только нужный горшок.
   Закрой это приложение, чтобы освободить устройство.
4. Установи `opencv-python` в отдельное Python окружение клиента.
5. Проверь связь командой `python camera/capture_agent.py --config private/camera/folium-camera-private.json --check`.
   Она не включает камеру.
6. Включи точку на сайте. Запусти ту же команду без `--check`. Для одного снимка
   используй `--once`, для выбора USB устройства — `--camera-index 1`.
7. Остановка: Ctrl+C либо выключение точки на сайте. Состояние перечитывается каждые
   десять секунд; сервер отвергнет загрузку, если точку выключили во время съёмки.

Клиент открывает камеру только для очередного кадра и освобождает после него.
Сохранение проверяет интервал последнего принятого снимка. При ошибке пишет только
тип ошибки; ключи не выводятся. Автозапуск при загрузке Windows не установлен.
Программные тесты используют подменный кадр; работа с физической камерой ещё
требует проверки после покупки.

Адрес по умолчанию из сайта подходит для того же ПК. Для отдельного компьютера
нужно настроить шлюз устройств сервера и изменить origin в приватном JSON.
HTTP допускается только для localhost/частного IP, внешнее подключение требует
HTTPS. Перенаправления с ключом запрещены.
